# RisuBard v0.9.19

v0.9.19는 캐릭터의 중요한 장면을 모아 감상하는 `갤러리`를 추가하고, 위키 프롬프트 프리셋 생성과 BardWiki 미리보기 및 Plugin API v3 호환성을 개선한 업데이트입니다.

## [기능] 캐릭터 기억 갤러리

- **장면 기억과 감상:** 캐릭터 툴바의 `갤러리`에서 원하는 메시지 범위를 독립된 기억으로 저장하고, 제목과 자동 미리보기로 장면을 찾아 기본 채팅 렌더링 그대로 다시 감상할 수 있습니다.
- **분류와 자유로운 배치:** 기억을 정사각형 슬롯으로 정리하고 분류별로 접거나 펼칠 수 있으며, 편집 모드에서 슬롯 크기·순서·분류·표시 메시지를 직접 조정할 수 있습니다.
- **선택적 패키지 공유:** 갤러리는 일반 캐릭터 및 채팅 익스포트에 자동 포함되지 않습니다. `공유`의 `갤러리` 항목을 직접 체크한 캐릭터 패키지에서만 기억을 내보내고 가져옵니다.
- **캐릭터 툴바 정리:** 기존 TTS 위치에 갤러리 버튼을 배치하고, TTS 설정은 `고급 설정`의 Bias 위로 옮겼습니다.

## [편의성] 위키 프롬프트 프리셋 생성

- **새 프리셋 버튼:** 위키 프롬프트 프리셋의 `기본 정보`에서 `새 프리셋`을 눌러 안전한 기본 계약과 편집 가능한 가이드 블록을 갖춘 독립 프리셋을 만들고 바로 선택할 수 있습니다.

## [UI] BardWiki 마크다운 미리보기

- **미리보기 스크롤 복구:** BardWiki 분할 작업 공간에서 긴 마크다운 문서의 미리보기를 끝까지 스크롤할 수 없던 문제를 수정했습니다.

## [호환성] Plugin API v3 제공자 등록

- **콜백 옵션 등록:** Plugin API v3의 `Risuai.addProvider()`에서 `overrideRequestStatus`에 동적 콜백을 지정해도 `DataCloneError` 없이 제공자와 모델이 정상 등록됩니다.
