# RisuBard v0.9.20

v0.9.20은 로어 항목을 AI와 함께 구조적으로 작성하는 `로어 빌더`를 추가하고, Gemini 3.8 Flash 모델 프리셋과 사이드바 퀵 인벤토리 정렬 피드백을 보강한 업데이트입니다.

## [기능] 로어 빌더

- **항목별 AI 편집:** 로어북과 그리모어의 각 항목 본문에서 로어 빌더를 열어 현재 초안을 다듬거나 새 구조화 Markdown 본문을 작성할 수 있습니다. 결과는 사용자가 `현재 항목에 적용`을 누르기 전까지 원본에 반영되지 않습니다.
- **선택적 컨텍스트 주입:** 시스템 프롬프트, 캐릭터 설명, 관련 캐릭터 로어와 모듈 로어북을 개별 선택할 수 있습니다. 관련 캐릭터 로어는 사용자 지시와 현재 초안에 맞춰 기존 로어북 또는 Grimoire 검색 규칙으로 선별하며, 편집 중인 항목은 중복 주입하지 않습니다.
- **로어북 전용 프리셋:** 공개·비공개 정보, 지식 경계, 복선과 공개 조건을 구조화하는 한국어·영어 기본 프리셋을 제공하며 사용자 프리셋을 별도로 저장하고 수정할 수 있습니다.
- **안전한 반복 작업:** 생성 중지, 빈 초안 리셋, 이전 초안 복원과 명시적 적용 동작을 제공하고, 스크롤·키보드 포커스·중첩 확인창의 표시 계층을 보장합니다.

## [호환성] Gemini 3.8 Flash 모델 프리셋

- **주요 제공자 지원:** Gemini 3.8 Flash를 Google AI Studio, Vertex AI 네이티브·OpenAI 호환, OpenRouter, Vercel AI Gateway, LLM Gateway와 NanoGPT에서 모델 프리셋으로 선택할 수 있습니다.
- **Vertex 모델 목록 보완:** Vertex AI의 OpenAI 호환 모델 목록을 최신 레지스트리에 맞춰 Gemini 3.7 Flash와 Gemini 3.8 Flash를 모두 제공합니다.

## [UI] 퀵 인벤토리 정렬 피드백

- **드롭 위치 표시:** 사이드바 퀵 인벤토리에서 캐릭터나 폴더를 드래그하면 현재 드롭 대상에 초록색 테두리를 표시하고, 대상에서 벗어나거나 드래그를 끝내면 자동으로 제거합니다.
