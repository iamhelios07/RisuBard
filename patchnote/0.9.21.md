# RisuBard v0.9.21

v0.9.21은 BardWiki 문서 탐색과 구조화 출력 오류 복구를 개선하고, 퀵 인벤토리 드래그 정렬과 폴더블 모바일의 사이드바 표시를 더 안정적으로 다듬은 업데이트입니다.

## [편의성] BardWiki 문서 링크

- **미리보기에서 바로 이동:** Markdown 미리보기의 `[[문서]]`와 `[[문서|표시 이름]]` 링크를 클릭하거나 키보드로 선택하면 해당 BardWiki 문서로 바로 이동합니다. 문서 이름과 별칭을 모두 지원하며, 연결되지 않거나 중복되어 대상을 확정할 수 없는 링크는 이동하지 않도록 구분합니다.

## [안정성] 구조화 출력 오류 복구

- **게이트웨이 오류 원인 인식:** OpenRouter 같은 게이트웨이가 provider 오류를 감싸서 반환해도 내부의 실제 오류 메시지를 인식합니다. Gemini가 구조화 출력 스키마를 거부한 경우 기존 폴백 재시도가 정상적으로 작동하고, 오류 화면과 요청 로그에도 실제 원인이 표시됩니다.

## [안정성] 레거시 로어북 호환

- **누락 키 안전 처리:** 오래된 카드나 내장 모듈의 로어 항목에 보조 키가 없어도 입력 시 오류로 중단되지 않고, 존재하는 이름과 활성화 키만 사용합니다.

## [편의성] 퀵 인벤토리 드래그 정렬

- **삽입 위치 표시:** 캐릭터를 드래그하면 카드 테두리 대신 실제로 배치될 카드 사이 공백에 초록색 위치선을 표시합니다. 사이드바가 한 열일 때는 위아래, 여러 열일 때는 좌우 위치를 드롭 결과와 동일하게 안내합니다.

## [호환성] 폴더블 모바일 사이드바 안정화

- **화면 번쩍임 방지:** Galaxy Z Fold7 등 일부 Android 폴더블 환경에서 사이드 메뉴를 열면 내용 영역이 검게 번쩍이던 현상이 발생하지 않도록 사이드바 전환 방식을 개선했습니다.

## [편의성] 하이파메모리 기본 동작 정리

- **기본 비활성화:** 신규 데이터와 하이파메모리 설정값이 없는 기존 채팅에서는 하이파메모리가 기본적으로 꺼진 상태로 시작합니다. 사용자가 명시적으로 켠 기존 설정은 유지됩니다.
- **메뉴 설정 반영:** 환경 설정의 `메뉴에서 하이파 모달 보이기`를 끄면 채팅 메뉴뿐 아니라 캐릭터 설정에서도 하이파메모리 모달 버튼을 표시하지 않습니다.

## [편의성] 로어·페르소나 편집 작업 공간 개선

- **자유로운 창 크기 조절:** 로어 빌더와 페르소나 빌더 창 가장자리의 리사이즈 핸들로 원하는 크기로 조절할 수 있습니다. 모바일에서는 화면 밖으로 벗어나지 않도록 자동으로 맞춰집니다.
- **컨텍스트 선택 정리:** 주입할 컨텍스트 선택 항목을 한 줄로 모으고 글자 크기를 다듬어 작업 영역을 더 넓게 확보했습니다.
- **원본·수정본 비교:** 하단 초안 영역의 원본과 수정본을 정확히 같은 크기로 맞췄습니다. 각 영역을 따로 스크롤할 수 있고 중앙 핸들로 너비를 조절할 수 있으며, 좁은 화면에서는 세로로 배치됩니다.
- **빈 수정본으로 시작:** 빌더를 열었을 때 수정본은 비어 있으며, AI가 생성한 결과만 수정본에 표시되어 원본과 결과를 명확히 구분할 수 있습니다.
- **로어 편집 버튼 강조:** 로어 빌더와 조건 보기 버튼의 글자 크기와 굵기를 높이고, 로어 빌더에는 마법 완드 아이콘과 밝은 배경을 적용해 진입점을 쉽게 찾을 수 있습니다.
- **바깥 영역으로 닫기:** 로어 빌더, 페르소나 빌더, 페르소나 관리자 등 겹쳐 열린 창은 바깥 영역을 클릭할 때 가장 위의 창부터 하나씩 닫힙니다.
