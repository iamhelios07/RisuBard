# RisuBard v0.9.22

v0.9.22는 앱 시작과 캐릭터·채팅 로딩 속도를 개선하고, 환경설정의 탐색 계층과 모듈·플러그인 관리 화면을 다듬은 업데이트입니다. 채팅 프롬프트 프리셋의 소개 정보를 관리하고 불필요한 저장 데이터를 한 번에 정리할 수 있습니다.

## [성능] 앱 시작 경량화

- **시작 작업 경량화:** 대용량 데이터베이스를 시작 과정에서 불필요하게 한 번 더 복제하거나 콘솔에 출력하던 작업을 제거했습니다. 자동 자산 정리를 사용하지 않을 때는 저장소 전체를 훑지 않고 필요한 원격 데이터 범위만 확인합니다.
- **초기 화면 코드 축소:** 환경 설정 화면은 실제로 열 때 별도로 불러오도록 분리해 앱 시작 시 읽고 처리해야 하는 코드량을 줄였습니다.

## [성능] 캐릭터와 긴 채팅 로딩

- **캐릭터 전환 최적화:** 이미 최신 형식인 캐릭터는 전환할 때마다 로어북과 전체 채팅을 다시 정리하지 않습니다. 오래된 데이터에는 기존 호환성 변환을 그대로 적용합니다.
- **긴 채팅 병렬 로딩:** 첫 페이지로 전체 분량을 확인한 뒤 남은 채팅 페이지를 최대 4개씩 병렬로 불러와, 메시지가 많은 캐릭터의 대기 시간을 줄였습니다.

## [안정성] Firefox 채팅 표시

- **Firefox 로딩 멈춤 방지:** 채팅 데이터를 받은 뒤 화면 갱신 신호가 늦어져도 `채팅 데이터 로딩 중` 상태에 계속 머물지 않고 내용을 표시합니다.

## [편의성] 환경설정 탐색 구조 개선

- **채팅 프롬프트 프리셋 분리:** 채팅 프롬프트 프리셋을 `AI 및 생성` 내부에서 분리해 같은 섹션의 독립 페이지로 옮겼습니다. 사이드바에서는 `AI 및 생성` 바로 아래에서 열 수 있습니다.
- **상위 탭 계층 강조:** 각 환경설정 페이지의 상위 탭은 강조색 배경과 큰 굵은 글자를 사용하는 둥근 탭으로 표시합니다. 페이지 내부의 보조 탭은 기존 형태를 유지해 현재 탐색 단계가 쉽게 구분됩니다.
- **페이지 정렬 통일:** 모듈과 플러그인을 포함한 환경설정 페이지의 제목, 본문 시작 위치와 좌우 여백을 공통 레이아웃에 맞췄습니다. 서로 다른 페이지를 이동해도 콘텐츠 기준선이 일정하게 유지됩니다.

## [기능] BardWiki 작성 언어

- **위키 작성 언어 확장:** BardWiki 사건·정본·스토리 아크를 한국어, 영어, 일본어, 간체중국어, 번체중국어로 작성할 수 있습니다. 이 선택은 앱 UI 언어와 독립적으로 적용됩니다.

## [편의성] BardWiki MD 미리보기

- **MD 미리보기 기억:** BardWiki 에디터의 `MD` 체크박스 상태를 저장해 문서를 바꾸거나 사이드바를 다시 열어도 마지막 선택을 유지합니다.

## [안정성] PageFold 정본 갱신

- **PageFold 정본 갱신 복구:** PageFold가 구조화 출력 거절 사유를 일반 공급자 오류로 감춰도 BardWiki가 호환 형식으로 전환해 정본 갱신을 다시 시도합니다.

## [안정성] 플러그인 공급자 요청 처리

- **무한 요청 대기 방지:** BardWiki 정본 갱신에 쓰는 PageFold 같은 플러그인 공급자가 응답이나 내부 스트림을 끝내지 않아도 설정된 네트워크 제한 시간이 지나면 실패로 처리하고 `요청 중` 상태를 종료합니다.
- **비동기 상태 창 오버라이드:** Plugin API v3 제공자가 `overrideRequestStatus` 콜백을 사용해 자체 생성 정보 창을 표시할 때, 비동기 반환값도 기다려 RisuBard 요청 상태 창이 중복 표시되지 않습니다.

## [호환성] Gemini 3.8 구조화 출력

- **Gemini 3.8 구조화 출력 호환:** Gemini 3.8 요청도 3.7과 같은 JSON Schema 필드를 사용해 구조화 출력 설정이 일관되게 전달됩니다.

## [UI] 모바일 저장·불러오기 화면

- **모바일 저장·불러오기 화면 복구:** 모바일에서 채팅 저장·불러오기 창이 화면 왼쪽 위로 밀려 일부만 보이던 문제를 수정했습니다.

## [UI] 채팅 프롬프트 프리셋 기본 정보 배치

- **조밀한 기본 정보 배치:** 아이콘과 이름을 같은 행에 배치하고, `복제하기`·`내보내기`·`불러오기`·`삭제하기` 버튼을 한 행에 모아 화면의 불필요한 여백을 줄였습니다. 좁은 화면에서는 버튼 아이콘만 표시합니다.

## [기능] 채팅 프롬프트 소개

- **프롬프트 소개 추가:** 프리셋의 용도와 안내를 기록할 수 있는 `프롬프트 소개` 필드를 추가했습니다. 소개글의 웹 주소는 Shift+클릭으로 열 수 있으며, 소개 정보는 프리셋 파일의 선택 필드로 저장되어 기존 파일과 호환됩니다.

## [편의성] 모듈·플러그인 관리자 개편

- **자유로운 관리자 크기 조절:** 데스크톱에서 모듈과 플러그인 관리자 영역의 상하좌우 가장자리와 모서리를 드래그해 작업 공간을 원하는 크기로 조절할 수 있습니다.
- **공통 카드 레이아웃:** 두 관리자가 같은 폴더 사이드바, 검색 도구, 카드 간격과 액션 버튼 구조를 사용합니다.
- **다중 선택과 묶음 이동:** 모듈·플러그인 카드의 위·아래 이동 버튼 대신 선택 체크 버튼을 두고, 카드 본문을 끌어 순서를 바꾸거나 폴더로 옮길 수 있습니다. 여러 항목을 고르면 묶음 드래그·일괄 삭제를 할 수 있고 검색 왼쪽의 `선택 취소`로 한 번에 취소합니다.
- **폴더 항목 2행 구성:** 폴더 이름과 파일 수는 첫 행에 유지하고, 위·아래 이동·이름 수정·삭제 버튼은 둘째 행에 모아 좁은 사이드바에서도 정보와 동작이 겹치지 않습니다.
- **모듈 정보 밀도 개선:** 모듈 카드에서는 활성·비활성 문구와 내부 네임스페이스 같은 중복 정보를 제거하고 제목과 설명을 세로 중앙에 정렬했습니다. 활성화·페르소나 할당과 수정·삭제를 각각 세로 열로 배치했으며, 활성 모듈은 버튼 배경 대신 활성화 아이콘만 파란색으로 표시합니다.
- **일관된 액션 버튼:** 모듈과 플러그인의 액션 버튼을 같은 크기, 간격과 테두리 스타일로 통일했습니다. 모듈 다운로드는 목록에서 제거하고 모듈 수정 화면으로 옮겼습니다.

## [기능] 플러그인 소스 편집

- **목록에서 코드 편집:** 각 플러그인의 `<>` 버튼으로 현재 JavaScript 코드를 바로 열어 수정하고 적용할 수 있습니다.
- **현재 코드 다운로드:** 코드 편집기에서 현재 편집 중인 내용을 JavaScript 파일로 내려받을 수 있습니다.
- **설정값 유지:** 수정한 코드를 적용해도 기존 플러그인의 활성 상태와 호환되는 설정값은 유지됩니다.

## [시스템] 고아 데이터 한 번에 정리

- **통합 정리 도구:** 기존 미참조 오브젝트 전용 버튼을 `고아 데이터 모두 정리`로 확장했습니다. 현재 사용하지 않는 미디어, HypaMemory 벡터와 미참조 저장 오브젝트를 한 번에 검사하고 정리하며, 실행 전 항목 수와 용량 및 완료 후 종류별 결과와 확보한 공간을 표시합니다.
- **참조 재확인 후 삭제:** 정리 직전에 캐릭터·페르소나·모듈·플러그인 등 현재 데이터의 참조를 다시 확인하며, 플러그인 저장소를 안전하게 검사할 수 없으면 미디어 삭제를 중단합니다. 인레이 이미지는 오인 삭제를 막기 위해 인레이 갤러리에서 별도로 관리합니다.
