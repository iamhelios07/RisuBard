# RisuBard v0.9.30

V1 저장 안정성을 보존하면서 0.9.26에서 누락된 독립 개선을 복원했습니다. 프롬프트 에디터 V2의 본문 표시, 위치 기억, 토글 탐색과 비주얼 조건 편집도 개선했습니다.

## [기능] 현재 챗 설정과 BardWiki 검색 보조 복원

- **챗 설정 작업 공간:** 현재 챗 설정을 작동 방식·검색·분석/응답·정본 작성으로 나누고, 챗 규모에 맞춘 옵션별 도움말과 현재 값을 전역 기본값으로 적용하는 기능을 복원했습니다. 설정창 크기도 조절하고 기억할 수 있습니다.
- **바드쨩 검색 재정렬:** 검색 점수가 비슷한 후보를 선택적으로 한 번 재정렬하며, 보조 호출이 실패하거나 결과가 잘못되면 기존 검색 결과를 그대로 사용합니다.
- **분석 입력 분리:** 응답 생성과 별도로 BardWiki 분석에서 사용자 메시지를 제외할 수 있고, 현재 챗에서만 값을 덮어쓸 수 있습니다.
- **과거 턴 재분석:** 각 AI 응답 하단의 돋보기 버튼으로 해당 턴과 이전 문맥을 현재 위키 설정에 맞춰 다시 분석할 수 있습니다. 사건 누락은 교체해 복구하고, 캐릭터의 최신 현재 상태는 과거 내용으로 덮어쓰지 않습니다.
- **Wiki Prompt V2 편집:** 위키 프롬프트에서도 V2의 원문·비주얼 편집, 조건 설정, 토글 미리보기와 찾기·바꾸기를 사용할 수 있습니다. 기본 프리셋은 잠그고 복제본의 코어 계약은 빨간 제목으로 구분해 편집할 수 있습니다.

## [기능] Grimoire 검색·분석 개선

- **직접 언급 우선:** 현재 입력에서 직접 언급한 항목의 우선순위, 마지막 유효 사용자 입력 기준, 댓글·비활성 메시지 제외와 후보 제외 사유를 도움말에 다시 명시했습니다.
- **새 챗 첫 메시지 검색:** 새 채팅의 첫 메시지에 나온 장소·인물을 최근 대화 범위 안에서 검색 단서로 사용해, 일반적인 첫 사용자 입력에서도 장면에 맞는 로어와 `ambient` 등장인물을 찾습니다.
- **그리모어 프롬프트:** 환경설정의 위키 프롬프트 바로 아래와 AI 메타데이터 분석 창에서 실제 분석 지시문을 확인할 수 있습니다. 기본값은 보호되고 복제본만 수정할 수 있으며, 진행 중 작업은 시작 시 지시문을 보존합니다.
- **분석 분류 강화:** 상태창·필수 출력 형식은 항상 필수 규칙으로, 긴 등장인물 명부·타임라인은 검색 인덱스와 개별 항목으로, 장소·소속 관계는 근거가 있을 때 `ambient` 링크로 제안합니다.
- **분석 창 공간 활용:** 숫자 설정을 두 열로 압축하고 설정·요청 계획 사이에도 리사이즈 핸들을 추가했으며, 대상 목록이 창의 남는 높이를 사용하도록 조정했습니다.

## [편의성] 페이지·턴 탐색 강화

- **고정 가능한 사이드 네비게이터:** 현재 페이지의 처음·이전 메시지·다음 메시지·끝 이동 버튼은 본문 옆에 유지하고, `환경설정 > 환경 > 접근성 > 스크롤`에서 자동으로 사라지지 않게 고정할 수 있습니다.
- **페이지·턴 바로가기:** 메시지 입력창 위 세이브/로드 툴바의 오른쪽 끝에서 목표 페이지와 그 페이지 안의 AI 응답 순번을 지정해 이동할 수 있습니다. 입력한 턴이 페이지의 마지막 응답을 넘으면 마지막 응답으로 이동합니다.
- **응답 턴 번호:** 각 AI 응답의 제목 왼쪽과 하단에 같은 턴 번호를 표시해 긴 대화에서도 메시지를 쉽게 참조할 수 있습니다.

## [편의성] 새 챗의 페르소나 승계

- **현재 정체성 유지:** 같은 캐릭터에서 새 챗을 만들면 이전 챗의 유효한 페르소나를 이어받고, 이전 챗이 없으면 마지막으로 선택한 전역 페르소나로 시작합니다.

## [편의성] 모듈 적용 범위 정리

- **모듈 적용 범위:** 채팅 안 모듈 창의 `챗` 버튼은 현재 캐릭터의 기존·새 챗 전체에 적용되며, 개별 챗의 기존 모듈 설정을 덮어쓰지 않습니다.

## [편의성] 파일 드롭 가져오기

- **파일 드롭 가져오기:** 앱 창에 놓은 모듈·프롬프트 프리셋·JavaScript 플러그인을 알맞은 목록으로 가져오고, 진행·완료·실패를 현재 언어로 안내합니다. 캐릭터 파일도 읽기·압축 해제·에셋 저장 단계를 표시합니다.

## [편의성] 프롬프트 V2 탐색과 조건 편집 개선

- **편집 위치 기억:** 다른 설정 탭이나 `프롬프트 블록`·`토글 구성` 사이를 오가도 마지막 선택 블록, 원문·비주얼 모드와 각 편집기의 스크롤 위치를 복원합니다.
- **토글 사용처 탐색:** 토글 변수마다 현재 프롬프트의 사용 횟수를 표시하고, 펼친 목록에서 블록 이름·줄 번호·주변 미리보기를 눌러 마지막 편집 모드를 유지한 채 해당 위치로 이동할 수 있습니다.
- **비주얼 조건 블록 조작:** 비주얼 모드에서 조건 블록 전체를 드래그해 옮기거나 잘라내고 삭제할 수 있습니다.
- **채팅별 토글 고정 갱신:** 사이드바의 고정된 토글 버튼에서 `현재 설정으로 덮어쓰기`와 고정 해제를 선택할 수 있습니다. 덮어쓰면 현재 선택값이 `직접 설정`으로 고정되고, 되돌리기의 기준값도 함께 갱신됩니다.

## [UI] 프롬프트 에디터 V2 표시 수정

- **포커스 텍스트 겹침 해소:** 조건 활성화 상태가 표시된 본문을 클릭해 편집할 때 미리보기 글자와 원문 글자가 겹치지 않도록 수정했습니다.

## [UI] 작업 진행 상태 표시

- **로딩 상태 안내:** Realm 조회와 로컬 이미지 읽기의 진행·실패·시간 초과를 화면 우측 아래에 표시하고, 시작 로고가 준비되기 전에 사라지는 깜빡임을 줄였습니다.

## [안정성] 빌더 스타일 프리셋 유지

- **선택 복원:** 페르소나 빌더와 로어 빌더에서 고른 스타일 지시 프리셋을 저장하고, 창을 다시 열거나 앱을 재실행해도 같은 프리셋 이름과 본문을 복원합니다.

## [안정성] 원격 접속 연결 복구

- **원격 접속 연결 복구:** Cloudflare가 자동으로 QUIC 또는 HTTP/2 연결을 선택하게 해 UDP가 제한된 네트워크에서도 접속할 수 있으며, 터널 연결이 확인된 뒤에만 QR 코드와 링크를 표시합니다. 화면을 열어 둔 동안 연결 종료나 서버 응답 실패를 감지하면 오류와 재시도를 안내하고, Android Firefox가 서버를 찾지 못할 때 DNS over HTTPS를 끄는 설정 경로도 보여 줍니다.

## [안정성] 모듈 파일 무결성 검사

- **불완전한 파일 차단:** 잘린 모듈이나 선언한 에셋 수와 실제 데이터가 다른 모듈을 일부만 가져오지 않으며, 내보낼 이미지가 없을 때 빈 파일을 정상 에셋처럼 넣지 않습니다.

## [안정성] 세이브·로드 상태 안내

- **세이브 확인창 표시:** 현재 채팅을 덮어쓰는 불러오기 확인창이 세이브 창 위에 표시되고, 확인하기 전에는 불러오기 버튼을 로딩 상태로 바꾸지 않습니다.
- **조용한 저장 표시:** 짧은 저장에는 저장 아이콘을 띄우지 않고, 오래 걸리는 저장만 작은 고정 아이콘으로 표시합니다.

## [시스템] V1 백업·이전 도구 통합

- **한곳에서 백업 관리:** 전체·설정 전용 백업과 복원, 업스트림 호환 백업, 저장 폴더 가져오기·정리, 부분 백업과 데이터셋 내보내기를 `시스템 > 백업`에 모았습니다.
- **기존 경로 호환:** 예전 이전 메뉴 경로를 열면 시스템 백업 탭으로 자동 이동하며, V1 백업 함수를 그대로 사용합니다.

## [시스템] 저장 구조 관찰 시작

- **저장 구조 관찰 시작:** 기존 저장 결과를 바꾸지 않고 전체 데이터 재조립·호환 저장·파일 반영에 걸린 시간과 쓰기 규모를 내용 없이 기록해, 이후 저장 구조를 작은 단계로 안전하게 개선할 근거를 수집합니다.

## [문서] V1 성능 개선과 점진 전환 계획

- **저장 안정성 우선 검증:** 이전 버전의 최적화를 이식 가능한 항목과 제외할 항목으로 나누고, 단계별 성능 측정·실제 세이브 복제 검증·중단 및 롤백 기준을 [계획서](../docs/superpowers/plans/2026-09-11-v1-safe-performance-backport.md)에 정리했습니다. 저장 구조 자체는 일괄 이관 대신 관찰부터 시작해 경계 하나씩 교체합니다.
