저장소를 RisuBard V2 구조로 이관합니다

이 버전을 사용하려면 기존 저장소를 한 번 이관해야 합니다.

  • 캐릭터·대화·페르소나·모듈·프롬프트를 이름별 폴더로 정리합니다. 같은 이름은 번호로 구분하며 내부 연결은 유지합니다.
  • 설명·프롬프트·로어북·이미지를 각 소유자의 폴더에 펼칩니다. 이미지 교체 후 새로고침하면 반영됩니다.
  • 새 활성 저장소에서 구형 통합 DB와 변환된 중복 에셋을 정리합니다. 이전 폴더와 복구 기록을 포함한 기존 저장소 전체는 아래 백업 경로에 보존합니다.
  • 필요한 문서·썸네일만 읽고 변경된 파일만 저장해 시작·로딩·저장 부담을 줄입니다. 실제 속도는 데이터와 PC에 따라 달라집니다.

원본 백업은 자동 삭제하지 않으므로 그 용량은 계속 사용합니다. 정상 동작과 새 전체 백업의 복원을 확인한 뒤 정리할 수 있습니다. 이관 중에는 다른 RisuBard 서버와 파일 편집기를 종료해 주세요.

이관 전 별도 로컬 백업 (선택)

기존 저장소 전체를 별도 폴더에 복사하고 검증합니다. 앱의 .bin 백업 파일과 다른 원본 폴더 백업이며, 복구 안내도 함께 저장합니다. 백업 후 자동으로 이관하지 않습니다.

이 기기의 폴더 경로를 입력하세요. 지정한 폴더 안에 고유한 백업 폴더를 새로 만듭니다. 원본 크기만큼 추가 공간이 필요합니다.
